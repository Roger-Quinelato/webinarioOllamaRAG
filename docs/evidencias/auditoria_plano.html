§1

Decisões de arquitetura

Acordadas na fase de grilling antes da implementação; citadas aqui como foram aplicadas no código.

Sem framework
Python puro — sem LangChain/LlamaIndex — para o mecanismo do RAG ficar visível linha a linha. Dependências fixadas com == em requirements.txt.
Sem Colab
Tudo local, em .venv dentro do projeto; nunca instalado no Python global.
Modelos via Ollama
Embedding bge-m3 (plano B nomic-embed-text); chat qwen2.5:3b (plano B qwen2.5:1.5b), selecionáveis por variável de ambiente.
Corpus
6 artigos do arXiv em inglês (Lewis 2020, Karpukhin 2020, Gao 2023, Es 2023, Asai 2023, Liu 2023) + 1–2 artigos em português — escolha do autor, pendente (E1 · 1.8).
Metadados
metadados.csv escrito à mão: arquivo, titulo, autores, ano, veiculo, tema, idioma, resumo. tema em vocabulário fechado. Resumo gerado pelo LLM a partir do abstract, no idioma original.
Chunking
Por página, com páginas longas subdivididas por tamanho fixo (1000 caracteres) com sobreposição (150).
Busca
Top-k simples → filtros where do ChromaDB → busca em dois estágios (1º nos resumos escolhe os artigos; 2º busca os chunks dentro deles).
SHAP
(a) palavras da pergunta × similaridade do chunk, ao vivo; (b) Shapley dos chunks na resposta, pré-computado. Explica o retrieval, não o raciocínio do LLM.
Prompt
Instruções numa mensagem system separada dos trechos + pergunta na user. Mudança feita após o 3b responder em inglês / recusar perguntas com prompt único (ver E6).
Streamlit
Chat com histórico, slider de k, filtros de metadados, alternância busca simples × dois estágios, fontes com resumo do artigo.
